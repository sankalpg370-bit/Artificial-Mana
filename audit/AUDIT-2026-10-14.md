## Database security follow-up

Supabase SDK version 2.117.3 is now pinned exactly. Supabase advisors found two mutable function search paths and externally callable privileged role helpers. The functions were hardened and role helpers moved into the unexposed `mana_private` schema. A follow-up advisor scan no longer reports those warnings; PostgreSQL permission tests and an anonymous catalog query pass. `database/hosted-function-hardening.sql` records the forward migration for the original schema, while the fresh-install schema includes the same protections already.

The remaining advisor warning is [disabled leaked-password protection](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection). The INFO notice for `comment_limits` having RLS without policies is intentional: browsers have no privileges on that internal counter; only its restricted trigger function accesses it.
