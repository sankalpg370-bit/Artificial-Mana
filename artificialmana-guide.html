1. What this project is

Artificial Mana is a learning website. It teaches artificial intelligence with videos.

Students watch lessons, take quizzes, write notes, draw on boards, and ask questions. Teachers make the courses in a form. Nobody must edit code to add a course.

7. How a teacher makes a course

  1. Log in with a teacher account.
  2. Click Admin in the top bar.
  3. Write a title, a description, and a category. Click Make course.
  4. Upload your video to YouTube.
  5. In the course, paste the YouTube link. Write the lesson title.
  6. Add a PDF file or quiz questions if you want.
  7. Click Add lesson. Repeat for each lesson.
  8. Click Publish. The public site shows the course in about 1 minute.

Use the arrows to move a lesson. Use Edit to change a lesson. A course needs one lesson or more to show on the site.

8. Set up on your computer

  1. Install Node.js, LTS version 20.9 or newer.
  2. Unzip the project. Open a terminal in the folder.
  3. Run npm install.
  4. Copy .env.local.example to .env.local.
  5. Add your Supabase URL and anon key. Find them in Supabase, Project Settings, API.
  6. Run npm run dev.
  7. Open http://localhost:3000.

9. Set up the database

  1. Make a free project at supabase.com.
  2. Open the SQL Editor. Click New query.
  3. Paste the whole file supabase-all.sql.
  4. Click Run. Do this one time only.
  5. Sign up on your site.
  6. Open database-steps/supabase-step8.sql. Find the last line.
  7. Remove the -- at the start. Write your email. Run that one line.
  8. Log in again. The Admin button shows.

10. Put the site online

  1. Run npm run build. Make sure there are no errors.
  2. Upload the project to GitHub. Do not upload .env.local.
  3. Make a Vercel account. Import the GitHub project.
  4. Add the two Supabase keys in Vercel, under Environment Variables.
  5. Click Deploy.
  6. In Vercel, open Settings, Domains. Add artificialmana.com.
  7. Copy the DNS records from Vercel to your domain company.
  8. In Supabase, open Authentication, URL Configuration. Set the Site URL to https://artificialmana.com.
  9. Turn on email confirmation again if you turned it off for tests.
  10. Test the live site with a new account on your phone.

Important. Vercel's free plan is for non-commercial use. Move to a paid plan before you sell courses or show ads.

11. Safety rules

  • Never share .env.local. Never upload it to GitHub.
  • The anon key is public by design. The database rules (RLS) protect the data.
  • A user cannot change their own role. A user cannot fake the Teacher badge.
  • Notes keep only safe formats. Scripts and links are removed.
  • Comments show as plain text. A user can post 5 comments in one minute.
  • Keep a copy of every video and every PDF on your own computer.
  • Write your own text on the About and Privacy pages. Ask a legal expert to check the Privacy page.
  • Run npm audit every month. Update the packages when a fix exists.
  • Run npm test before you put a change online. All tests must pass.
  • Run npm run test:e2e with a separate test project. It creates test accounts and course data.
  • Do not use the live Supabase project for browser tests. Put test passwords in the ignored .env.local file.

13. Problems and fixes

ProblemFix
"Supabase keys are not set"Check .env.local. Stop the site. Run npm run dev again.
npm install or build failsRun node -v. You need version 20.9 or newer.
SQL shows "already exists"You ran the file twice. This is safe to ignore.
No email after sign-upCheck the spam folder. For tests, turn off email confirmation in Supabase.
The Admin button does not showRun the role line. Log out. Log in again.
A new course does not showWait 1 minute. Make sure it is published and has one lesson or more.
The teacher board does not updateMake sure supabase-all.sql ran with no errors. Open the board again.
No certificate buttonFinish all lessons. Pass every quiz with 60% or more.
Certificate shows a name errorUse English letters in the name.
"Download notes as PDF" shows nothingAllow pop-ups for the site. Try again.
